# Ambient sound recordings (optional)

Windowsill generates every sound in the browser, so these files are **optional**. If you
add a recording with the exact name below, it replaces the generated sound.

```
public/sounds/beach/waves.mp3        public/sounds/mountain/wind.mp3
public/sounds/beach/seagulls.mp3     public/sounds/mountain/birds.mp3
public/sounds/beach/wind.mp3         public/sounds/mountain/stream.mp3
public/sounds/breaks/rain.mp3        (played during breaks, if chosen)
```

- **Format:** MP3 (or rename to match), 30–120 s, made to loop (Windowsill loops it with no gap).
- **Size:** ~1 MB per minute at 128 kbps mono is plenty for ambience.
- **License:** CC0 (Freesound) or Pixabay license only, and add every file to `CREDITS.md`.

The sound mixer in Focus Mode shows "recording" next to a sound when your file is being used.
