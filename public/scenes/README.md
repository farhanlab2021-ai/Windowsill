# Scene videos (optional)

Windowsill draws both scenes in code, so these files are **optional**. If you add a
video with the exact name below, Focus Mode plays it instead of the drawing.

```
public/scenes/beach/day.mp4       public/scenes/mountain/day.mp4
public/scenes/beach/sunset.mp4    public/scenes/mountain/sunset.mp4
public/scenes/beach/night.mp4     public/scenes/mountain/night.mp4
```

Optional still images with the same names (`day.jpg`, …) are shown while a video loads.

- **Format:** MP4 (H.264), no audio track, 1920×1080 or 1280×720, 10–30 s that loops smoothly.
- **Size:** aim for **under 6 MB each** (see the ffmpeg command in the main README).
- **License:** only free-for-commercial-use clips (e.g. Pexels or Pixabay license), and add
  every file to `CREDITS.md`.

See "Adding real scenery and sounds" in the main README for search tips.
